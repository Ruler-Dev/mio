Power features

  • Drag-drop any PDF / text / code file onto the window — auto-extracted and attached to next message.
  • 🎤 Voice input (Web Speech). /convo for hands-free conversation loop (TTS reads replies).
  • /screenshot captures any window or screen as an attachment.
  • /workspace picks a local folder for live read/write. /save drops current artifact there.
  • /ambient floats the last response above all apps via Picture-in-Picture.
  • /focus zen mode · /gallery artifact browser · /search across all chats (top of sidebar).
  • Hover any message for Copy · Regenerate · Speak · Pin buttons.
  • Edit any artifact in-place via the Source tab → Save creates a new version. Prev/Next arrows navigate versions.
  • Drag the left edge of the artifact panel to resize. Double-click to toggle fullscreen.
  • Clipboard watcher — copy an image elsewhere then click back to the window, you'll be offered "Attach?"
  • Wake Lock keeps the screen awake during long generations. Notifications ping you when the tab is unfocused and a reply finishes.
